Understanding the CSS Box Model

Every element is a box made up of content, padding, border, and margin. The universal rule box-sizing: border-box includes padding and border in an element's declared width.

Box model labels

MARGIN — space outside the border
BORDER — edge around the element
PADDING — space inside the border
CONTENT — text, images, or other elements
